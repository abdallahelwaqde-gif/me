# لوحتي — نسخة التطبيق (PWA)

الملفات:
- `index.html` التطبيق كله (HTML + CSS + JS)
- `manifest.webmanifest` بيانات التثبيت
- `sw.js` بيخلّي التطبيق يشتغل من غير نت بعد أول زيارة
- `icons/` الأيقونات

## النشر على GitHub Pages (مجاني)
1. أنشئ مستودع جديد على GitHub (مثلًا `my-life-board`).
2. ارفع كل محتويات هذا الفولدر في جذر المستودع (مش الفولدر نفسه).
3. من Settings ← Pages: اختر Branch = main وFolder = /(root) ثم Save.
4. بعد دقيقة افتح الرابط `https://USERNAME.github.io/my-life-board/`.

## التثبيت على الموبايل
- أندرويد/كروم: افتح الرابط ← قايمة المتصفح ← "تثبيت التطبيق" (أو الزر داخل تاب تحفيز).
- آيفون/سفاري: زر المشاركة ← "إضافة إلى الشاشة الرئيسية".

## ملاحظات مهمة
- لازم يتفتح من رابط https (مش من ملف على الجهاز) عشان التثبيت والعمل من غير نت يشتغلوا.
- البيانات بتتحفظ على الجهاز نفسه. مفيش تزامن بين الأجهزة في النسخة دي، فاستخدم "تصدير نسخة احتياطية" و"استيراد" عشان تنقلها.
- التذكير بيشتغل لما التطبيق يكون مفتوح، ومفيش إشعار بيوصل وهو مقفول (ده محتاج سيرفر).
- لو عدّلت `index.html` بعد النشر، غيّر `life-board-v1` في `sw.js` لـ `life-board-v2` عشان التحديث يوصل للمستخدمين.
